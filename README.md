# ⏱️ مؤقت المشاريع

تطبيق شخصي بسيط لقياس وقت المشاريع بالساعات. ملف واحد (`index.html`) يعمل في أي متصفح على الجوال أو الحاسوب، دون خادم ودون إنترنت.

## المميزات

- **مؤقتات لكل مشروع**: زر بدء/إيقاف مع عدّاد حيّ يتحدّث كل ثانية.
- **الواجهة الرئيسية**: تُظهر مجموع ساعات العمل اليوم عبر كل المشاريع.
- **يوم العمل يبدأ الساعة ٥ صباحاً** وينتهي بعد ٢٤ ساعة. أي عمل قبل الخامسة صباحاً يُحسب على اليوم السابق، ويُصفّر المجموع تلقائياً عند الخامسة صباحاً.
- **مؤقت واحد نشط** في نفس الوقت: بدء مشروع يوقف المشروع العامل تلقائياً حتى لا تُحتسب الساعات مرتين.
- **هدف يومي** قابل للتعديل مع شريط تقدّم يوضّح نسبة الإنجاز من الهدف.
- **تقارير أسبوعية وشهرية**: مخطط لساعات كل يوم (مع مؤشّر الهدف) وتوزيع الوقت حسب المشروع، بالإضافة إلى المعدّل اليومي وعدد الأيام التي تحقّق فيها الهدف.
- **تعديل يدوي للوقت**: إضافة أو طرح ساعات/دقائق لأي يوم (لجلسة نسيت تشغيلها أو أوقفتها متأخراً)، مع سجل كامل لكل الجلسات وإمكانية حذف أي منها.
- **حفظ تلقائي** في المتصفح (localStorage) — بياناتك تبقى بعد إغلاق التطبيق.
- **إضافة / تعديل / حذف** المشاريع.
- **تصدير / استيراد** البيانات كملف JSON للنسخ الاحتياطي أو النقل بين الأجهزة.
- تصميم عربي (RTL) يدعم الوضع الفاتح والداكن تلقائياً.
- **تطبيق ويب تقدّمي (PWA)**: قابل للتثبيت على الجوال بأيقونة على الشاشة الرئيسية، ويعمل بملء الشاشة **بدون اتصال بالإنترنت** بعد فتحه أول مرة.

## التثبيت على الجوال (PWA)

يحتاج الـ PWA إلى استضافة عبر رابط **HTTPS**. أسهل طريقة مجانية هي GitHub Pages:

1. من صفحة المستودع على GitHub: **Settings → Pages**.
2. تحت **Source** اختر **Deploy from a branch**، ثم اختر الفرع الذي يحتوي الملفات والمجلد **/(root)**، ثم **Save**.
3. بعد دقيقة سيظهر رابط بالشكل: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.
4. افتح الرابط على جوالك:
   - **أندرويد (Chrome):** سيظهر زر **«تثبيت التطبيق»** داخل التطبيق، أو من قائمة المتصفح **«تثبيت التطبيق / إضافة إلى الشاشة الرئيسية»**.
   - **آيفون (Safari):** زر المشاركة ⬆️ ثم **«إضافة إلى الشاشة الرئيسية»**.

بعد التثبيت يعمل التطبيق كتطبيق مستقل بدون شريط المتصفح، ويعمل حتى بدون إنترنت.

## ملفات المشروع

- `index.html` — التطبيق كاملاً (واجهة + منطق).
- `manifest.webmanifest` — بيانات الـ PWA (الاسم، الأيقونات، وضع العرض).
- `sw.js` — الـ Service Worker للعمل دون اتصال.
- `icons/` و`apple-touch-icon.png` — أيقونات التطبيق.

## ملاحظة حول البيانات

البيانات محفوظة محلياً داخل المتصفح/الجهاز المستخدَم (localStorage). لنقلها إلى جهاز آخر استخدم زر **تصدير البيانات** ثم **استيراد** في الجهاز الآخر.
