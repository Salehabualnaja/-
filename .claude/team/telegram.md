# ربط فريق السحابة بتيليجرام

بعد الربط يصير تيليجرام هو مكان التواصل مع الفريق: ترسل الرسائل والملفات من جوالك، فيصل كل ملف إلى مكانه في «فريق السحابة»، ويصلك الرد في المحادثة نفسها.

## كيف يعمل

```
جوالك (تيليجرام) ⇄ بوتك ⇄ Claude Code على حاسوبك (في هذا المستودع) ⇄ Google Drive «فريق السحابة»
```

- يعمل Claude Code على **حاسوبك**، ولا يعمل الربط من الجلسة السحابية.
- **يرد البوت ما دام Claude Code يعمل.** إذا أُغلق الحاسوب أو أُغلقت النافذة توقف البوت عن الرد.
- الميزة اسمها **Channels**، وهي تجريبية، وقد تتغير أوامرها.

## الإعداد (مرة واحدة، نحو 15 دقيقة)

### 1) ثبّت الأدوات على حاسوبك

| | macOS أو Linux (الطرفية Terminal) | Windows (PowerShell) |
|---|---|---|
| Claude Code | `curl -fsSL https://claude.ai/install.sh \| bash` | `irm https://claude.ai/install.ps1 \| iex` |
| Bun | `curl -fsSL https://bun.sh/install \| bash` | `powershell -c "irm bun.sh/install.ps1 \| iex"` |
| Git | يكون مثبّتاً غالباً | من git-scm.com |

بعد التثبيت أغلق الطرفية وافتحها من جديد، ثم تحقّق بالأمرين `claude --version` و`bun --version`.

### 2) نزّل المستودع

```bash
git clone https://github.com/Salehabualnaja/-.git saha-team
cd saha-team
git checkout claude/clever-cannon-bksksf
```

لا تحتاج أمر `git checkout` بعد دمج الفرع في الفرع الرئيسي.

### 3) أنشئ البوت

في تيليجرام افتح **@BotFather**، وأرسل `/newbot`. اختر له اسماً، مثل «فريق السحابة»، واختر معرّفاً ينتهي بـ `bot`، مثل `saha_team_bot`. سيعطيك BotFather **توكن**: انسخه ولا تشاركه مع أحد.

### 4) ثبّت إضافة تيليجرام

داخل مجلد المستودع شغّل `claude` وسجّل الدخول بحساب claude.ai، ثم اكتب:

```
/plugin install telegram@claude-plugins-official
```

اختر نطاق **user** عند السؤال. إن ظهر الخطأ `Marketplace "claude-plugins-official" not found` فاكتب أولاً `/plugin marketplace add anthropics/claude-plugins-official` ثم أعد أمر التثبيت.

ثم أدخل التوكن:

```
/telegram:configure <التوكن>
```

### 5) أعد التشغيل مع القناة

اخرج من Claude Code (`/exit`)، ثم شغّله بهذا الأمر:

```bash
claude --channels plugin:telegram@claude-plugins-official
```

### 6) اربط حسابك

أرسل أي رسالة لبوتك في تيليجرام، فيرد عليك برمز. ثم اكتب في Claude Code:

```
/telegram:access pair <الرمز>
/telegram:access policy allowlist
```

الأمر الثاني يجعل البوت لا يستجيب لأحد غيرك.

### 7) تأكد من وصول Claude Code إلى Google Drive

اكتب `/mcp` وتأكد أن **Google Drive** و**Google Sheets** يظهران متصلين، فهما يأتيان من موصلات حسابك في claude.ai. إن لم يظهرا فاربطهما من إعدادات الموصلات في claude.ai، ثم أعد تشغيل Claude Code.

### 8) طلبات الإذن

في الأيام الأولى سيسألك Claude Code في الطرفية قبل كل أداة جديدة. اختر **«Yes, and don't ask again»** للأدوات الآمنة: القراءة، والإنشاء في Drive، والرد في تيليجرام. بعد ذلك يعمل دون مقاطعة.

لا تستعمل `--dangerously-skip-permissions`.

## الاستعمال اليومي

1. افتح الطرفية في مجلد المستودع، وشغّل `claude --channels plugin:telegram@claude-plugins-official`.
2. اترك النافذة مفتوحة والحاسوب مستيقظاً.
3. تواصل من تيليجرام.

### صيغ الرسائل

| تكتب | يحدث |
|---|---|
| `أسامة: …` | يتولّى أسامة الطلب، وكذلك أي رسالة بلا اسم |
| `مشروع جديد: <الاسم> — <البرنامج> — <سطر وصف>` | يبني أسامة مجلد المشروع وبطاقته ويضيفه إلى السجل |
| ملف أو صورة ومعها تعليق `سكن` | يُرفع الملف إلى «سكن / 01-مدخلات» ويصلك رابطه |
| ملف بلا تعليق | يُرفع إلى «01-وارد»، ويسألك أسامة عن مشروعه |
| `أعطني <ملف> — <المشروع>` | يصلك رابط الملف من Drive |
| `وضع <المشروع>` | يصلك ملخّص البطاقة والخطوة التالية |

### حدود الملفات

- الملفات المرسلة إلى البوت: حتى **20MB** للملف. هذا حد تيليجرام.
- الصور: أرسلها **كملف** (اضغط مطوّلاً ثم Send as File) لتصل بجودتها الأصلية.
- الملفات الأكبر: ارفعها إلى Drive مباشرة، وأرسل رابطها في تيليجرام.
- الملفات التي يرسلها البوت إليك: حتى **50MB** للملف.

## فهم الرسائل الصوتية العربية

> **الحالة على حاسوب البيت: معطّل.** ميزة Smart App Control في Windows تحظر مكتبات أداة التفريغ (PyAV). البديل المعتمد هو **إملاء لوحة المفاتيح** في الجوال: اضغط 🎤 في لوحة المفاتيح، وتكلّم، فيُكتب كلامك نصاً عربياً، ثم أرسله للبوت. الإعداد أدناه يبقى مرجعاً إن تغيّر ذلك لاحقاً.

يفرّغ البوت رسائلك الصوتية إلى نص **على حاسوبك نفسه**، بنموذج Whisper. لا يخرج الصوت إلى أي خدمة خارجية، ولا توجد تكلفة. الأداة في `tools/transcribe.py`.

### الإعداد (مرة واحدة) في PowerShell

```
winget install Python.Python.3.12
```

أغلق PowerShell وافتحه من جديد، ثم نفّذ:

```
python -m pip install faster-whisper
```

### الاستعمال

أرسل رسالة صوتية للبوت، فيرد بسطر «🎙️ سمعت: …» ثم ينفّذ طلبك.

- **أول رسالة صوتية** تستغرق دقائق، لأن النموذج (نحو 1.6GB) يُنزَّل مرة واحدة فقط.
- **بعدها** يستغرق تفريغ دقيقة من الصوت قرابة نصف دقيقة إلى دقيقة، بحسب قوة المعالج.
- **إن كان الجهاز بطيئاً،** فاختر نموذجاً أصغر:
  ```
  setx WHISPER_MODEL medium
  ```
  ثم أعد تشغيل `start-telegram.cmd`.
- **الحد الأقصى للحجم** 20MB للرسالة الصوتية الواحدة، وهذا حد تيليجرام.

## التشغيل الدائم على حاسوب البيت

الملف `start-telegram.cmd` يجلب آخر تحديثات الفريق (`git pull`)، ثم يشغّل Claude مع القناة. وإذا توقف Claude أعاد تشغيله تلقائياً بعد 15 ثانية. ولإيقافه أغلق النافذة.

- **التشغيل مع Windows:** اضغط `Win+R`، واكتب `shell:startup`، ثم اضغط Enter. ضع في المجلد الذي يُفتح **اختصاراً** إلى `start-telegram.cmd`.
- **منع النوم:** من الإعدادات اختر «النظام» ثم «الطاقة»، واضبط «الشاشة» و«السكون» على «أبداً».
- **إعادة تشغيل التحديثات:** من الإعدادات اختر «Windows Update» ثم «الخيارات المتقدمة» ثم «ساعات النشاط»، واجعلها تغطي ساعات عملك. بعد أي إعادة تشغيل يجب أن تسجّل الدخول إلى Windows حتى يعمل الفريق من جديد.
- **نسخة واحدة فقط:** لا تشغّل البوت على جهازين في الوقت نفسه بالتوكن نفسه، لأن تيليجرام لا يسلّم الرسائل إلا لنسخة واحدة.

## الأمان

- التوكن محفوظ في `~/.claude/channels/telegram/.env` على حاسوبك فقط. لا تضعه في المستودع.
- البوت لا يستجيب إلا لحسابك، بعد خطوة `policy allowlist`.
- لا يُرسَل شيء لعميل، ولا يُنشر، ولا يُحذف، إلا بموافقتك الصريحة. هذا كما في `CLAUDE.md`.
