# MINDSPACE

منصة للتفكير وإدارة المعرفة المعقدة. تكتب الأفكار على لوحة لا نهائية، وتحوّلها إلى كيانات وعلاقات ذات معنى، ثم تراها في جداول ولوحات معلومات تُحسب من الشبكة نفسها.

- **المعمارية ونموذج البيانات**: [`ARCHITECTURE.md`](ARCHITECTURE.md)
- **المراحل ومعايير القبول وحالة كل بند ونتائج الأداء**: [`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md)

## التشغيل المحلي

المتطلبات: Node.js 22.12 أو أحدث.

```bash
cd mindspace
npm install
npm run dev          # ثم افتح http://localhost:3000
```

لا حاجة إلى Docker ولا إلى إعداد: تُستعمل قاعدة PostgreSQL مدمجة (PGlite)، وتُحفظ البيانات في `mindspace/.data/pglite`. والمجلد مستثنى من git.

### مع خادم PostgreSQL حقيقي (اختياري)

```bash
docker compose up -d                 # PostgreSQL 17 على المنفذ 5432
cp .env.example .env                 # ثم ضع في الملف:
# DATABASE_URL=postgres://mindspace:mindspace@localhost:5432/mindspace
npm run dev
```

الهجرات (`drizzle/`) تُطبَّق تلقائياً عند أول اتصال.

### نسخة إنتاجية

```bash
npm run build
npm start            # المنفذ 3000
```

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm test` | اختبارات الوحدة والاستمرارية (Vitest، على PostgreSQL حقيقي عبر PGlite) |
| `npm run test:e2e` | اختبارات المتصفح (Playwright). شغّل `npm run build` قبلها |
| `npm run typecheck` · `npm run lint` | فحص الأنواع وESLint |
| `npm run bench` | قياس الأداء عند 1,000 كيان و3,000 علاقة |
| `npm run bench -- --seed http://localhost:3000` | يضيف بيانات الأداء نفسها إلى تطبيق يعمل، في لوحة مستقلة |
| `npm run db:generate` | توليد هجرة بعد تعديل `src/server/db/schema.ts` |

## الاستعمال السريع

| الإجراء | الطريقة |
|---|---|
| فكرة جديدة | انقر نقراً مزدوجاً على مساحة فارغة، أو استعمل زر «كيان» |
| علاقة | اسحب من حافة بطاقة إلى بطاقة أخرى، ثم اختر نوع العلاقة. وإن أفلتّ في الفراغ تنشأ بطاقة جديدة مرتبطة |
| تعديل العنوان | انقر نقراً مزدوجاً على البطاقة، أو Enter |
| التفاصيل | انقر على البطاقة أو الخط |
| إزالة من اللوحة فقط | Delete (يبقى الكيان في «الوارد») |
| حذف من النظام | من التفاصيل أو من القائمة بالزر الأيمن، مع تأكيد |
| تحديد مجموعة | Shift مع السحب، أو أداة التحديد في الشريط |
| تراجع / إعادة | Ctrl+Z / Ctrl+Shift+Z |
| نسخ / لصق / لصق كنسخة / تكرار | Ctrl+C / Ctrl+V / Ctrl+Shift+V / Ctrl+D |
| ملاءمة المحتوى / التركيز على المحدد | Shift+1 / Shift+2 |
| بحث وأوامر | Ctrl+K |
| التقاط سريع (فكرة في كل سطر) | زر «الوارد» في الشريط العلوي |
| السيناريو التجريبي | القائمة ☰ ثم «تحميل السيناريو التجريبي» (في لوحة مستقلة) |

## تنبيه

النسخة الحالية لمستخدم واحد بلا تسجيل دخول. شغّلها على جهازك أو شبكتك الخاصة فقط، ولا تعرضها على الإنترنت.
